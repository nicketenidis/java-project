# Property Rental Platform

 - This is project where I develop a property rental platform n Java, supporting user registration, authentication, property browsing, rentals and reviews.
<br>
- Implemented role-based functionality for two user types: **property owners and simple renters**<br>
- Authenticated renters could browse available properties, rent properties, and submit reviews for rented properties. On the other hand, authenticated owners could add, delete  or modify their revisiting properties.<br>
- Firstly, the application was implemented as a Command-Line Interface (CLI) and then I redesigned it as a Graphical User Interface (GUI).
